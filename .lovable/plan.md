# 舞遍世界主頁與首頁導流優化

## 目標
- 首頁「🌍 舞遍世界～文化小百科」改為精準前往 `/world-dance`。
- 讓 `/world-dance` 成為使用莫蘭迪暖色世界地圖的正式文化探索主頁。
- 將地圖下方「熱門民俗探索」升級為具攝影張力與明確導流的互動卡片。

## 執行內容
1. **路由與導流**
   - 新增 `/world-dance` 路由並保留既有 `/styles` 相容入口。
   - 修改首頁中段 CTA 的連結，避免進入舊版頁面。

2. **舞遍世界主頁**
   - 使用現有經緯度定位、可互動的莫蘭迪暖色世界地圖。
   - 調整主頁標題與版面層級，讓地圖成為首屏核心。

3. **熱門民俗探索卡片**
   - 建立 3 張高品質舞蹈攝影卡片，呈現巴爾幹群舞、佛朗明哥與以色列社交舞。
   - 每張卡包含舞種名稱、地域／文化標籤與一句特色介紹。
   - Hover 時照片輕微放大並浮現「👉 探索文化與課程」按鈕；觸控裝置則維持按鈕可見。
   - 點擊卡片導向相應文化內容區段，並保留後續課程探索入口。

4. **驗證**
   - 驗證首頁 CTA 路由、`/world-dance` 頁面載入、卡片互動，以及桌面／行動版排版。

## 技術細節
- React Router 增加正式路由。
- 沿用既有語意色彩 token、Playfair Display／Noto Sans TC 與 Framer Motion。
- 圖片存放於專案資產中，不使用外部圖片熱連結。
